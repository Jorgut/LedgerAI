# 衡账 LedgerAI · 发布与社交媒体营销计划

更新：2026-11-12。参考 BizPeel 上已验证营收的消费类 App 案例，结合衡账「本地优先、无账号、离线、买断」定位制定。

> 核心结论：**先等 App Store 审核通过拿到可下载链接，再开始放量；预热可以现在做，但所有帖子必须先有“产品可下载”这个落点。**
> BizPeel 案例证明：消费级 App 不需要网站流量，**一条“前后对比”的短视频/图文 + 一个明确差异点**就能起量。

## 1. 从 BizPeel 案例里提炼的 6 个可复制打法

| 案例 | 公开数据 | 可复制的动作 | 衡账怎么用 |
|---|---|---|---|
| **FaceKit**（iPhone 订阅制，全部收入来自 IAP） | MRR **$26.7K**、累计 $282K、6,005 订阅、网站月访问仅 5,341；一条 X 爆款帖“$10K in 8 days” | **「前后对比」演示 + X 爆款帖 + 置顶串链到购买页**；不依赖网站 | 做「一张乱糟糟的小票 → 3 秒变成一笔干净账单」的 15 秒视频/GIF；X 置顶 thread 附 App Store 链接 |
| **PokéItem**（卡片扫描 + 订阅/终身） | 30 天 $30.3K、MRR $19.6K、3,106 订阅；€5.99/月、€49.99/年、**€159.99 终身** | **创作者短链（/go/、/r/）嵌入垂直内容**；免费额度钩子（1000 张免费卡位、每月限 20 次扫描） | 小红书/B 站 KOC 用专属下载链接/二维码；免费版不限制核心记账，Pro 才给同步/多账本/高级报表 |
| **GarageLab**（AI 车图） | 30 天 $4.1K、累计 $12.5K | 免费下载 + IAP/订阅；用视觉冲击内容在社交分发 | 小票 OCR 的“识别瞬间”本身就是视觉冲击；录屏比截图更有传播力 |
| **Ritmo**（运动社交） | MRR $10.3K、+327%/30 天；网站月访问仅几百 | **社区/线下活动驱动**，网站几乎不带量 | 在小红书/微信群/豆瓣「抠门/省钱/记账」话题里做真实用户故事，而不是打广告 |
| **GotAll**（身高预测） | 年收入 $880K、MRR $55.8K、1.72 万订阅 | 免费预测 → 付费墙；社媒账号长期运营 | 免费记账 → 1.1 的买断 Pro；先积累真实用户和评分，再上付费墙 |
| **Tether Mobile**（一人公司） | MRR $2.5K，靠创始人 X 发帖起量 | 创始人/开发者本人持续发帖（build in public） | 你自己出镜/发开发者日志：为什么做一个不登录、不联网的记账 App |

**共同点：**
1. 获客几乎都来自**一个内容平台的一种内容形式**，不是全渠道铺开；
2. 内容必须有**“一眼看懂的变化”**（前后对比、识别瞬间、省钱数字）；
3. 网站不重要，**App Store 商品页就是落地页**；
4. 免费下载 + 订阅/买断是消费 App 主流，**终身买断可以作为差异化**；
5. 创始人/开发者本人的持续发帖比品牌号更有效；
6. 先有真实用户和评分，再放大投放。

## 2. 衡账的定位与可传播钩子

**一句话定位：**
> 「不用注册、不联网、可买断的记账 App——小票拍一下，3 秒记好一笔。」

**六个可验证的钩子（每条都能做成内容）：**
1. **不登录**：打开就能记，没有手机号/微信授权；
2. **不联网**：飞行模式全功能可用（可录屏演示）；
3. **不收集**：App Store 隐私标签 **Data Not Collected**（截图就是证据）；
4. **小票 OCR**：拍照 → 金额/商户/分类自动填好（15 秒前后对比）；
5. **语音记账**：说一句「午饭三十二块」→ 自动填好；
6. **买断制**：无订阅、无广告（1.1 上线后强调；现在可说“免费、无广告”）。

> 内容红线：不写“云端大模型”“AI 理财顾问”；不承诺收益；不买评/刷量（Apple 2.3 / 5.6，小红书也有商业内容规范）。

## 3. 渠道策略（按优先级）

### 3.1 小红书（首发主战场，中文用户）
- **目标**：首月 30–50 篇笔记，3–5 篇千赞，带来 3,000–10,000 次 App Store 点击。
- **账号矩阵**：
  - 官方号 1 个（产品介绍、更新、用户故事）；
  - 素人/KOC 20–30 个（1,000–5 万粉，记账/省钱/数码/适老化/隐私话题）；
  - 创始人号 1 个（build in public，真实感最强）。
- **内容形式优先级**：
  1. 15–30 秒录屏：小票拍照 → 金额自动填好 → 保存（前后对比）；
  2. 「被会员刺客逼疯后，我做了个不订阅的记账 App」故事帖；
  3. 「给爸妈装的记账 App」适老化实测；
  4. 「飞行模式也能记账」隐私实测；
  5. 「6 款记账 App 对比，只有它不注册」横评（注意客观，不贬低竞品）。
- **标题模板**（20 条备选见 §6）；
- **发布节奏**：上线前 3 天开始预热（不发下载链接，发开发日志/预告），上线当天集中发 5–8 篇，之后每天 2–3 篇；
- **注意**：商业合作笔记走蒲公英/报备；不要用“最”“第一”等绝对化用语；导流用 App Store 链接/二维码，不用“私信发安装包”。

### 3.2 X（全球/华人开发者圈，1.1 英文化后加大）
- **目标**：1 条置顶 thread + 每天 1–2 条 build in public；争取 1 条爆款（FaceKit 模式）。
- **内容**：
  - 置顶 thread：问题（记账 App 都要注册/订阅）→ 方案（不登录、离线、买断）→ 15 秒演示 → 隐私标签截图 → App Store 链接；
  - 日常：开发日志、OCR 识别对比、用户反馈、退款/隐私讨论；
  - 蹭话题：回复「subscription fatigue」「privacy-first apps」「indie iOS」相关热帖，提供真实观点，不硬广。
- **注意**：App 目前是中文 UI，X 上主要先打**中文/华人 + 隐私/独立开发者圈**；1.1 英文上线后再做 Product Hunt / Reddit / 英文 KOL。

### 3.3 B 站 / 知乎（长内容，建立信任）
- B 站：3–5 分钟「我为什么做一个不联网的记账 App」+ 实测视频；
- 知乎：回答「有哪些无广告的记账 App」「记账 App 为什么都要会员」等问题，附真实截图；
- 频率：每月 2–4 条，不求量，求搜索长尾。

### 3.4 其他（1.1 英文版后）
- **Product Hunt**：英文版上线当天发布，准备 5 张图 + 1 个 GIF + maker comment；
- **Reddit**：r/iosapps、r/personalfinance、r/PrivacyGuides（先参与讨论，再发 launch 帖，遵守各版规则）；
- **Hacker News**：Show HN（隐私/离线/买断角度）；
- **App Store 推荐**：提交 Featuring 表单（隐私/适老化/本地 AI 是 Apple 喜欢的叙事）。

## 4. 发布节奏（可直接执行）

| 时间 | 动作 | 产出 |
|---|---|---|

| **T+30** | 第二波：用户故事/UGC、版本更新、买断 Pro（1.1）上线活动；考虑小额投放 | 持续增长 |

## 5. 归因与衡量（不上第三方统计，保持隐私标签干净）

- **App Store Connect 活动链接（Campaign Links）**：为小红书、X、B 站、KOC 分别生成 provider token 链接，App Analytics 里看来源/转化；
- **促销码**：给 KOC/测评作者 100 个/版本的 promo code（Apple 上限），既能追踪又能给福利；
- **关键指标**：
  - App Store 产品页浏览 → 下载转化率（目标 ≥ 25%）；
  - 首日/首周下载（目标：首月 1,000–3,000）；
  - 评分数量与均分（目标：首月 30+ 评分、≥4.7）；
  - D1/D7 留存（目标 D7 ≥ 20%）；
  - 1.1 上线后付费转化（目标 ≥ 1.5%）。
- **不要**：接第三方统计 SDK（会破坏 Data Not Collected 与营销卖点）。
