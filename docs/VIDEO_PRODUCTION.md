# 15–30 秒演示视频升级方案（三场景 + 中文解说 + 自然转场）

更新：2026-11-12。目标：让 App 演示视频更“酷”、更像真实产品片，而不是截图拼贴。

## 一、Skill Atlas 检索结论

用 `skill-atlas recommend tool`（hybrid 模式）检索“带中文配音解说、自然转场、展示语音/手动/拍照三个场景”的结果：

- 本地可用技能里：`youtube-clipper`（视频剪辑/字幕）、`frontend-slides`（动效/封面）、`packy-image`（图像处理）最接近，但**都不是专门的 App 演示视频工具**；
- GitHub / 官方 Skills / MCP 注册表没有匹配到视频制作类技能（返回的官方技能不相关）；
- 结论：**Skill Atlas 负责“技能编排”，具体视频生产要用外部工具链**（下面这套）。

> 可用技能：`remotion-best-practices`（如果要程序化生成视频）、`apple-design`（动效审美）、`screenshot-planner`（商店截图/顺序）、`youtube-clipper`（剪辑/字幕）。

## 二、推荐工具链（macOS，从快到专业）

| 环节 | 工具 | 说明 |
|---|---|---|
| 录屏（iPhone 真机） | QuickTime Player + 数据线 | 免费、60fps，最真实 |
| 录屏（模拟器） | `xcrun simctl io <UDID> recordVideo` | 免费、可脚本化，适合反复录 |
| 录屏增强 | **Screen Studio**（付费）/ OBS（免费） | 自动缩放、光标平滑、镜头感；Screen Studio 最适合“产品片” |
| 配音 | **自己录**（最佳）/ 剪映 AI 配音 / ElevenLabs | 创始人亲自解说最动人；AI 配音先做小样 |
| 剪辑/转场/字幕 | **剪映专业版**（免费）/ Final Cut / DaVinci | 剪映的自动字幕、智能转场、9:16 模板足够 |
| 程序化动效 | **Remotion**（React，配合 `remotion-best-practices`） | 统一片头/字幕/设备框/版本变体，可复用 |
| 封面/缩略图 | Figma / Canva / PIL | 3 行大字 + 手机图 |

**推荐组合（首发最快）：** QuickTime 录屏 → Screen Studio 做镜头感 → 剪映剪辑 + 自动字幕 + 自己的配音 + 轻音乐。
**如果要系列化/多语言：** Remotion 做模板，录屏素材复用。

## 三、30 秒脚本（中文解说，可直接录）

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–3s | 黑底白字：删了 8 个记账 App | 「记账 App 我删了七八个，最后自己做了一个。」 |
| 3–8s | 拍照场景：小票 → 识别 → 金额/商户/分类填好 | 「拍一张小票，金额、商户、分类，3 秒自动填好。」 |
| 8–14s | 语音场景：按住说话 → 文字 → 自动填好 | 「不想打字？按住说一句：今天午餐花了 42 块。」 |
| 14–19s | 手动场景：键盘 → 分类 → 保存 | 「也可以手动记，大字号，爸妈也能用。」 |
| 19–24s | 飞行模式 + 隐私标签/设置页 | 「不登录、不联网、无广告，数据只在你手机里。」 |
| 24–30s | 首页/Logo + CTA | 「衡账，App Store 搜索『衡账』。」 |

**转场原则**（自然、不花哨）：
- 用动作匹配剪辑：手指按下「拍照」→ 切到识别完成；说「42 块」尾音→ 切到金额填好；
- 结果出现时做轻微 1.05 倍推近（0.3s），不要旋转/闪白；
- 场景之间用叠化 0.2–0.3s 或同方向滑动，保持节奏；
- 字幕与旁白逐句同步，关键词加粗；背景音乐 -18~-20dB。

## 四、分镜拍摄清单

1. **拍照**：小票放桌面 → 打开相机 → 对准 → 快门 → 结果页（金额/商户/分类）；
2. **语音**：点语音入口 → 按住说「今天午餐花了 42 块」→ 松开 → 识别文字 → 金额填好；
3. **手动**：点「+」→ 键盘输入 42 → 选「餐饮」→ 保存；
4. **隐私**：开飞行模式 → 正常记账 → 设置页数据说明；
5. **结尾**：首页 + App 图标 + CTA。

> 录制前开 `--dart-define=DEMO=true` 准备演示数据；状态栏时间固定 9:41；关闭通知/低电量。
> 建议增加一个仅 debug 的「演示脚本」快速走完三场景，便于反复录制。
