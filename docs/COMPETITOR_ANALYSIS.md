## 二、关键结论

1. **市场已经"免费 + IAP"内卷**：iCost 终身 ¥60、Cookie ¥68、木木 ¥68–128，且都带云同步、小组件、导入导出、AI/OCR。单靠"买断"不再是差异化，**必须有同样能打的功能底座**。
2. **隐私/离线是真实差异，但不是唯一**：iCost/Cookie 也声称无广告、不滥用数据，Cookie 还免费 iCloud 同步。我们的优势要落到"**完全不联网、不上传照片/语音、无账号**"并且**可验证**（飞行模式 + Data Not Collected）。
3. **适老化是头部没做透的空白**：大字号、语音优先、无弹窗、子女帮父母装——现有竞品都偏年轻用户。
4. **AI 方向已被咔皮/Cookie 占位**：我们做设备端 OCR/语音，准确率若不如云端，不要硬吹"AI 全能"；主打"够快、隐私、离线"，并把准确率打磨到可接受。
5. **价格锚点**：终身 ¥60–128；我们定 **¥48 创始 / ¥68 常规** 合理，但需要 1.1 补齐 iCloud 同步、小组件、账单导入，否则用户会拿 iCost ¥60 对比。

## 三、怎么打赢（不打正面，打细分）

### 定位
「**不登录、不联网、可买断的记账本**」——把"隐私 + 简单 + 适老"做到极致，而不是功能最全。

### 三类目标人群
1. **隐私敏感/反订阅人群**：不想把账单交给云端、讨厌会员墙；
2. **适老化家庭**：子女给父母装，字大、语音、无广告、一次性买断当礼物；
3. **极简主义者**：只需要快速记 + 看报表 + 预算，不要资产/黄金/物品/社区。

### 1.1–1.2 必须补齐的"入场券"功能
- iCloud 同步（多设备，CloudKit，不建服务器）
- 桌面/锁屏小组件
- 微信/支付宝账单 CSV 导入（迁移必备）
- 多账本/自定义分类（至少基础）
- 多币种（可选，海外）
- 数据导出/恢复（已具备，保持免费）

### 差异化功能（可选，按资源）
- **父母模式**：一键切换超大字号 + 语音引导 + 隐藏复杂功能；
- **离线 OCR/语音**：飞机模式演示，做成营销素材；
- **投资/理财视角**：定投/资产收益记录（契合你本人需求，和纯支出 App 区分）；
- **家庭共享**（后期，iCloud 共享，明确隐私）。

### 价格与渠道
- 免费核心 + Pro 买断：中国 **¥48 创始 / ¥68 常规**；全球 $6.99 / $9.99；
- 不做订阅（至少 1.x），不做广告；
- 小红书主攻"隐私/反订阅/适老"，X 等英文 1.1 后再放量。

## 四、App 名称优化建议

当前「衡账」2 字，品牌感好但**搜索词覆盖不足**。App Store 名称上限 30 字符，建议改成「品牌 + 场景词」：

| 方案 | 名称 | 说明 |
|---|---|---|
| A（推荐） | **衡账 - 不登录的记账本** | 保留品牌，补"记账"搜索词，差异点前置 |
| B | 衡账 · 离线记账 | 突出离线 |
| C | 衡账 - 无广告买断记账 | 突出无广告/买断（1.1 后再用） |
| D | 衡账本 | 更口语、搜索友好，品牌弱一点 |

副标题：**拍照语音记账，数据只在本机**（或"离线更安心"）。
关键词：记账,账本,预算,报表,OCR,语音,离线,隐私,无广告,买断,适老化,个人财务。
> 名称修改需在 App Store Connect 操作；建议等 build 3 审核通过后、1.1 版本一起改，避免审核中反复改元数据。
