# 衡账 · 命名研究与英文命名

更新：2026-11-12。当前 App Store 名称暂定：**衡账 - 不登录不联网的记账本**。

## 一、「衡」是什么意思

「衡」读 héng，本义是**秤杆/称重**，引申为：
- **衡量、权衡**：比较轻重、判断取舍；
- **平衡、对等**：收支平衡、心理平衡；
- **衡器**：古代观测天体的仪器（璇玑玉衡）。

「衡账」= 把账目称量清楚、让收支平衡。作为记账 App 名字，语义准确、克制、有东方感。

## 二、中文能不能只用「衡」？

可以，但各有取舍：

| 方案 | 优点 | 风险 |
|---|---|---|
| **衡**（单字） | 极简、品牌感强、图标/水印好做；英文可统一为 Heng | 太抽象，App Store 搜索「衡」会混入大量无关结果；少了「记账」品类词；单字商标/域名更难抢 |
| **衡账**（推荐） | 品牌 + 品类都清楚，搜索「记账」也能命中；中文语境自然 | 两字略正式，年轻用户可能觉得不够潮 |
| 衡本 / 衡簿 / 衡记 | 更口语/书卷气，含「本/账」 | 品牌辨识度弱于「衡账」 |

**建议**：App Store 展示名用 **「衡账 - 不登录不联网的记账本」**；图标/水印/社交头像可以用单字 **「衡」** 作为短品牌。这样既有品类搜索，又有简洁符号。

## 三、英文命名

| 英文 | 含义 | 评价 |
|---|---|---|
| **Heng** | 拼音，无英文歧义 | 最独特、易注册，但英语用户不懂含义，需要副标题解释；推荐 **Heng — Private Ledger / Heng: Offline Bookkeeping** |
| Balance | 平衡 | 语义好，但极其通用、商标拥挤，不建议 |
| Ledger | 账本 | 语义最准，但通用词 + Ledger SAS（硬件钱包）品牌冲突，不建议单独用 |
| Tally | 计数/记账 | 口语、好记，但同名 App/软件很多，商标风险 |
| Poise | 从容、平衡 | 气质好，但和记账关联弱 |
| Weigh | 称重（动词） | 语义直译，英文不自然 |
| Equilibrium | 平衡 | 太长，不适合 App 名 |

**推荐英文**：
- 品牌：**Heng**
- App Store 英文名：**Heng — Private Ledger** 或 **Heng: Offline Bookkeeping**
- 副标题/一句话：*Bookkeeping that stays on your phone.*

上线前需做：App Store 名称唯一性检查、商标查询（中国/美国/欧盟相关类别）、域名与社媒 handle 可用性。

## 四、当前决定

- 中文 App Store 名称：**衡账 - 不登录不联网的记账本**（方案 A）；
- 单字「衡」作为短品牌/图标水印候选，不等于 App Store 名称；
- 英文名 1.1 英文化时再最终确认（候选 Heng — Private Ledger）。
