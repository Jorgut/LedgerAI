## 二、常见问题（FAQ）

### 1. 我的记账数据会被上传吗？
不会。衡账不联网、没有服务器、不需要账号，账本只保存在你的 iPhone 本地。详见 [隐私政策](PRIVACY.md)。

### 2. 换手机怎么迁移数据？
1. 旧手机：「我的 ▸ 数据 ▸ 导出 JSON 备份」，通过系统分享保存到「文件」或发给自己；
2. 新手机：安装衡账后，「我的 ▸ 数据 ▸ 导入备份」，选择该 JSON 文件；
3. 导入前建议先导出一次新机现有数据，避免覆盖。
CSV 适合查看与做表，**JSON 才可用于恢复**。

### 3. 语音记账提示「本机语音识别不可用」？
衡账只使用**设备端**语音识别（不上传音频，也不会回退到服务器识别）。出现该提示时：
- 确认「iOS 设置 ▸ 衡账 ▸ 麦克风」与「语音识别」已允许；
- 在「iOS 设置 ▸ 通用 ▸ 键盘 ▸ 听写」中确认中文听写已启用、语音包已下载；
- 部分设备/系统版本对本机中文识别支持有限，此时请改用「拍照识别」或手动记账。

### 4. 拍照识别的金额不准怎么办？
- 尽量正对小票、避开反光与折痕，保证文字完整；
- 手写小票、褪色热敏纸的识别率有限，识别结果会填入表单，**请确认或修改后再保存**；
- 若图片过大或倾斜，可先裁剪再识别；
- 也可以在备注里补充文字，App 会据此修正分类。

### 5. 数据会丢吗？
数据保存在本机，App 升级不会清空账本。但**卸载 App、清空数据、恢复备份覆盖**都不可撤销，建议定期导出 JSON 备份。

### 6. 有广告或内购吗？会收费吗？
没有广告、没有内购、没有订阅，下载与全部功能免费。

### 7. 为什么没有登录、云同步、多设备共享？
这是刻意设计：不登录就没有账号泄露风险，不联网就没有数据被上传的可能。跨设备迁移请用 JSON 导出/导入。

### 8. 支持 iPad / Android / Apple Watch / 深色模式吗？
- v1 仅支持 **iPhone 竖屏**、iOS 16 及以上；iPad 与 Android 在后续版本评估中。
- 深色模式、高对比度、大字号线已支持：「我的 ▸ 外观」中切换；也可跟随系统。

### 9. 字体太小，父母看不清？
- 在「我的 ▸ 外观」开启大字号 / 高对比度；
- 或在「iOS 设置 ▸ 显示与亮度 ▸ 文字大小」整体放大，App 会跟随系统字号；
- 主要按钮不小于 48pt，图标按钮带旁白（VoiceOver）语义标签。

### 10. 怎么删除全部数据？
「我的 ▸ 数据 ▸ 清空全部数据」，需二次确认；确认后不可恢复。彻底移除请再卸载 App。

### 11. 为什么报表里的「本地建议」不是投资建议？
建议由你本机的账本数据统计得出（如「本月餐饮占比偏高」），只用于提醒消费结构，**不构成投资、理财、税务或法律建议**。

## 三、已知限制

- 拍照识别依赖图片质量：手写、模糊、反光、严重折痕的小票识别率有限，请识别后确认；
- 语音记账依赖设备端中文语音识别能力，部分设备/语言环境不可用（App 会明确提示，不会上传音频）；
- v1 仅 iPhone 竖屏，不含 iPad 布局、多币种、自动同步、账号体系；
- 数据仅存本机，换机需手动导出/导入 JSON。
