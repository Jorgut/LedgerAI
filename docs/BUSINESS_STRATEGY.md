# 衡账 LedgerAI · 商业化与竞争策略研究

更新：2026-11-12。作者：Lead（研究结论供用户决策）。配套现状见 `docs/PROJECT_STATE.md`。

> 一句话结论：**v1 先免费上架积累口碑；1.1 用「买断制 Pro」变现（中国 ¥48 创始 / ¥68 常规，全球 $6.99 / $9.99），不做微信/支付宝登录，不做订阅**；目标不是正面打赢钱迹/鲨鱼，而是切「不登录、不联网、买断、适老化」这个被大厂结构性忽略的细分。

---

## 1. 商业闭环怎么搭

记账类工具的商业闭环不是「做个付费墙」就结束，而是：

```
价值（3 秒记一笔 + 看得懂的报表）
  → 获客（App Store ASO / 小红书 / B 站 / 隐私与反订阅话题）
  → 首次价值（不登录、打开即用、离线可用）
  → 转化（Pro 买断：同步 / 多账本 / 高级报表 / 小组件）
  → 留存（每日提醒、预算预警、小组件、数据沉淀）
  → 口碑（数据可导出、无广告、无订阅、适老化 → 好评与转介绍）
  → 复购/升级（2.0 大版本、家庭共享、多端同步）
  → 再投入获客
```

当前状态：价值已交付、免费上架中；**缺的是转化（IAP）与获客**。所以 1.1 的核心不是加功能，而是加「值得付费的功能 + 付费墙 + 商店转化素材」。

## 2. BizPeel 调研：有没有同类已实现营收的项目？

BizPeel（[bizpeel.com](https://bizpeel.com/)）的验证逻辑是「通过公开支付渠道核对收入」，目前收录约 **799 个企业、637 个有验证收入**。我抓取并解析了其 Library 数据，结论：

| 发现 | 数据 |
|---|---|
| **没有消费级记账 App 的直接对标** | 全站 `direction=finance` 的只有 1 个：**Conductor**（QuickBooks 企业文件 API，MRR $4.8M），是 B2B 开发者工具，不可比 |
| **但消费级 iPhone IAP App 可以做到 $20–30K/月** | **FaceKit**：iPhone 订阅制 App，全部收入来自 IAP，MRR **$26.7K**、累计 $282K、6,005 个活跃订阅、网站月访问仅 5,341（靠 X 上一条爆款帖起量）——[报告](https://bizpeel.com/project/facekit) |
| | **PokéItem**：扫描收藏卡 App，30 天收入 **$30.3K**、MRR **$19.6K**、3,106 订阅；定价 €5.99/月、€49.99/年、**€159.99 终身**——[报告](https://bizpeel.com/project/pokeitem) |
| | **LocalGen**：纯设备端 iOS AI 图片应用，MRR **$1,983**（同类里偏小，说明纯离线工具增长更慢但成本极低） |
| **重要方法论提醒** | BizPeel 的收入来自 Stripe 等公开支付渠道；**纯 App Store IAP 的 App 大多不可见**（看不到 Apple 后台）。所以「BizPeel 里没有记账 App」≠「这个市场没钱」，只说明这类收入不透明 |

**可借鉴的三点：**
1. 消费工具类 IAP 现实天花板：**$20–30K MRR** 已经是 BizPeel 里很好的独立开发者水平（相当于年入 ~$240–360K，Apple 抽成后 ~$200–300K），不是「一个人做几个月就月入百万」。
2. **终身买断可以和高价订阅并存**（PokéItem €159.99 终身），说明「买断」在海外用户中是被接受的定价形态。
3. 增长靠 **一个内容渠道打穿**：FaceKit 靠 X 爆款 + before/after 演示；PokéItem 靠创作者短链和垂直社群。记账 App 对应的是小红书/B 站/知乎的「隐私、反订阅、适老化」内容。

> 因此：BizPeel 不能替你验证记账 App 的市场规模，但能验证「独立开发者做 iOS 消费工具 + 买断/订阅」这条路是成立的。真正的竞争数据要用 App Store 同类产品来对标（下一节）。

## 3. 竞争格局与定价锚点（中国区 App Store 实测）

| App | 评分/规模 | 定价 | 差异化 | 我们的相对位置 |
|---|---|---|---|---|
| **钱迹** | 4.9★ / 2.4 万评分 / 600 万+ 用户 / 财务榜 #123 | 月费 ¥6；年费 ¥36；**终身买断 ¥128** | 无广告/无开屏/无理财；AI 识别账单；多账本；共享账本；资产/信用卡/报销/退款；免费同步/导入/导出 | 功能比我们多一个数量级；但**要账号、要联网** |
| **一木记账** | 4.8★ / 7,678 评分 | 月费 ¥9.90；年费 ¥53；**永久 ¥116** | 语音/一句话记账；20+ 小组件；多资产/信贷/多币种；iCloud/WebDAV；共享账本 | 同上，功能强；我们赢在极简与隐私 |
| **鲨鱼记账** | 4.9★ / 234 万评分 / 财务榜 #28 | 连续包月 ¥15；包季 ¥38；**包年 ¥148** | 3 秒记账；云端账号同步；订阅制 | 体量最大；订阅反感人群是我们的机会 |

**定价结论：**
- 中国用户对记账 App 的**终身买断心理价位是 ¥100–130**（钱迹 ¥128、一木 ¥116 已验证）。
- 我们功能少于两者，价格应低一档：**¥68 常规价**，创始期 **¥48**；不要低于 ¥30（低价伤害长期定价能力，也让用户怀疑质量）。
- 全球：$9.99 常规、$6.99 创始；PokéItem 的 €159.99 终身说明海外可接受更高价，等我们 1.2 补上同步/多账本后可提价到 $14.99。
- 鲨鱼 ¥148/年订阅能卖动，说明「云端同步 + 持续服务」才配得上订阅；我们**纯本地、无服务器成本**，用订阅会显得不合理，反而破坏「买断、不被绑架」的品牌。

## 4. 定价与产品分层设计（推荐方案）

### 4.1 免费版（永远免费，且不阉割数据权）
- 手动/拍照/语音记账，单账本，分类、备注、搜索
- 基础月报（收支/结余/分类占比）、1 个月度预算
- CSV / JSON 导出与备份恢复（**数据可携带永远免费**，这是对钱迹/鲨鱼「导出锁会员」的正面差异）
- 深色模式、高对比度、系统大字、VoiceOver（**无障碍永远免费**）

### 4.2 Pro（一次性买断，非消耗型 IAP）
- iCloud 多设备同步（v1.1，CloudKit，无自建服务器）
- 多账本 / 多账户 / 自定义分类与图标
- 高级报表：同比环比、分类趋势、年度热力图
- 主屏/锁屏小组件
- 微信/支付宝账单 CSV 导入
- 面部识别/密码锁、自定义主题
- **中国 ¥68（创始 ¥48）；全球 $9.99（创始 $6.99）**；给已购用户「永久 1.x 更新」

### 4.3 订阅要不要做？
- **v1.x 不建议**：无服务器成本、无持续服务，订阅会招致「又一个订阅刺客」的差评，且 Apple 3.1.2 对自动续费披露要求严格（[Guidelines 3.1.1](https://developer.apple.com/app-store/review/guidelines/)）。
- 未来只有在出现**服务器成本**（多人共享账本、跨 Android/iOS 云同步、家庭账本）时，再对「云服务」单独订阅（如 $1.99/月、$14.99/年），本地功能仍保买断。
- 混合模式有数据支撑：RevenueCat 2025 报告显示 **35% 的订阅 App 同时提供消耗型或终身购买**（[State of Subscription Apps 2025](https://www.revenuecat.com/state-of-subscription-apps-2025/)），「买断 + 可选订阅」是大势。

### 4.4 创始人用户（前 100 / 前 1000）
**可以做，但要按 App Store 规则设计，否则不成立：**
- App Store 不允许用「名额」限制 IAP 销售；**促销代码每个版本每个平台最多 100 个**（[Apple 帮助](https://developer.apple.com/help/app-store-connect/offer-promo-codes/request-and-manage-promo-codes/)），所以「前 100 免费」可行（发给核心 TestFlight 测试者/测评作者），「前 1000 免费」不可行（没这个发放通道，还会把收入全免掉）。
- 推荐：**创始人 = 上线首 2–4 周内以 ¥48 / $6.99 买断的用户**，永久 Pro + 应用内「Founder」标识 + 优先支持；通过价格计划在窗口结束时回调到 ¥68 / $9.99。若一定要「前 1000 名」，可脚本每日拉 App Store Connect 销售报表，销量到 1000 时手动调价——但这只是运营动作，不要对外承诺无法自动保证的数字。
- 不要做「前 1000 免费送」，理由：① 收入为零；② 促销码最多 100；③ 免费用户对转化、评论、口碑的贡献并不比低价买断高；④ 日后无法区分「创始人」与「白嫖」。
- TestFlight 现在就能免费测试（已邀请 2 人）；正式发布后再用 100 个促销码做「核心测试者/测评作者」福利。

### 4.5 收入模型（供决策）
Apple 小企业计划：年收入 ≤ $1M 抽成 **15%**（[Small Business Program](https://developer.apple.com/app-store/small-business-program/)）。

| 场景 | 月新增安装 | 付费转化 | 价格 | 月净收入（扣 15%） |
|---|---|---|---|---|
| 保守 | 5,000 | 1.5% | ¥68 / $9.99 | ~$955 |
| 基准 | 20,000 | 2.0% | ¥68 / $9.99 | ~$3,400 |
| 乐观 | 50,000 | 2.5% | $9.99 | ~$10,600 |
| 参考系 | FaceKit 6,005 订阅 | — | 订阅制 | $26.7K/月 |

现实预期：**首年 $500–$3,000/月净收入**是合理区间；要达到 $10K+/月，需要稳定 ASO + 内容渠道，或海外放量。成本几乎只有 $99/年开发者年费 + 时间（无服务器、无广告投放），因此**现金流风险极低，但增长上限依赖获客**。

## 5. 能不能支持微信登录 / 支付宝登录？

### 5.1 技术上可以，但代价很大
| 项 | 微信登录 | 支付宝登录 |
|---|---|---|
| 前提 | 微信开放平台账号 + **企业/组织认证（300 元/年）**；个人主体不能申请移动应用登录能力（[资质说明](https://www.apppark.cn/t-58103.html)） | 支付宝开放平台企业认证 |
| 需要后端 | 是（code 换 openid、账号体系、同步、注销、数据存储） | 是 |
| 隐私/合规 | 需改隐私标签、隐私政策；收集用户标识/手机号；中国区需 APP 备案/个人信息保护合规 | 同左 |
| Apple 规则 | **4.8 条**：使用微信等第三方登录作为主账号，必须同时提供「仅收集姓名/邮箱、可隐藏邮箱」的等价登录（即 **Sign in with Apple**） | 同左 |
| 账号注销 | 5.1.1(v)：有账号就必须提供应用内注销 | 同左 |
| 支付 | **不能**用微信/支付宝卖 Pro（3.1.1 必须用 IAP） | 同左 |

结论：
- **推荐不做**。我们的卖点是「不登录、不联网、零收集」，加登录等于自毁定位，还要引入后端与合规成本，且**支付仍必须走 Apple IAP**，登录对收入没有直接帮助。
- 如果以后要跨设备同步：**首选 Sign in with Apple + iCloud/CloudKit**——不需要第三方 SDK、不需要中国主体认证、隐私口径不变，还能当 Pro 卖点。
- 如果以后做 Android：再上微信登录/微信支付/支付宝支付（Android 不受 Apple 3.1.1 限制），但要有企业主体与服务器。

## 6. 怎么和钱迹/鲨鱼竞争？

正面拼功能、拼免费、拼投放，打不赢。可执行的差异化打法：

1. **定位一句话**：「唯一不用注册、不联网、可买断的记账 App」。
2. **人群细分**：
   - 适老化：系统大字、语音优先、无广告弹窗、子女帮父母装（一次性买断当礼物）；
   - 隐私敏感：Apple 隐私标签 Data Not Collected 是硬证据，可截图宣传；
   - 反订阅人群：钱迹/鲨鱼会员与「导出锁会员」引发的不满（[用户迁移讨论](https://post.smzdm.com/p/ak8k0zme/)）是我们的机会。
3. **必须补齐的功能（1.1，按优先级）**：iCloud 同步 → 小组件 → 微信/支付宝账单 CSV 导入 → 多账本/多账户 → 自定义分类。缺同步和账本，用户试用后会回钱迹。
4. **把「AI」做成可信的**：钱迹已用云端 AI 识别账单；我们设备端 OCR 若准确率不足，会直接掉口碑。1.1 前必须用 50+ 张真实小票验证；不够就主打「语音/手动 3 秒 + 隐私」，不要过度承诺。
5. **渠道**：App Store ASO（记账/离线/无广告/买断/隐私/适老化/老人记账）；小红书/B 站/知乎做「不联网记账」「被会员刺客逼走的第 N 天」内容；英文版上 Product Hunt / Reddit r/personalfinance / Hacker News 的 privacy 叙事。
6. **护城河**：不是功能，而是**信任品牌 + 数据可携带 + 无障碍品质 + 极低运营成本**。大厂不会为了一个小众做「不登录、不联网、买断」。
7. **不要做**：广告（毁信任）、自建服务器（成本+合规）、付费墙锁导出（用户最恨）、订阅（与定位冲突）。

## 8. 风险与止損点

| 风险 | 应对 |
|---|---|
| OCR/语音准确率不如云端竞品 | 真机 50 张小票验证；不达标就调整定位（语音+手动+隐私），别硬吹 AI |
| 买断收入天花板低、获客贵 | 低成本运营；先做口碑与海外；1.2 再评估订阅云服务 |
| App Review 对 IAP/隐私的审查 | 1.1 用 IAP、恢复购买、隐私政策同步更新；测试账号与审核备注写清 |
| 中国区合规（备案/个人信息） | 保持纯离线是最大合规优势；一旦加服务器/登录，先咨询备案与 PIPL 合规 |
| 价格定太低难以上调 | 创始 ¥48 / 常规 ¥68；不要低于 ¥30；用功能升级支撑提价 |
| 大厂抄袭细分 | 拼速度与品牌；数据可携带 + 信任叙事 + 适老化品质是它们的成本盲区 |

## 9. 最终建议（给用户的决策清单）

1. **先免费上架**，1.1 再上买断 Pro——不要现在撤包改价。
2. **定价**：创始 ¥48 / $6.99，常规 ¥68 / $9.99；不做订阅；不做「前 1000 免费」。
3. **创始人计划**：TestFlight 核心测试者 + 上线首 2–4 周低价买断 + Founder 标识；100 个促销码用于测评作者。
4. **微信/支付宝登录：不做**；同步用 Sign in with Apple + iCloud（Pro）；Android 版本再考虑微信/支付宝。
5. **竞争**：放弃正面刚钱迹/鲨鱼，打「无账号、全离线、买断、适老化」细分；1.1 必须补 iCloud 同步与小组件，否则留不住用户。
6. **先验证再扩张**：用 1.1 的转化率与 D30 留存决定是否投入 Android/云服务/订阅；不达标就砍功能、降成本，别加服务器。
