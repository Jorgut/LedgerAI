# 衡记 LedgerAI · App Store 隐私标签逐项依据

> 结论：App Store Connect 隐私问卷中，**所有数据类型均选择「不收集」**，**Tracking 选择「否」**。
> 依据：Apple 对「收集（Collect）」的定义是「把数据从设备传输出去，使开发者或第三方能够访问」。
> 衡记的数据只写入本机 App 沙盒（Hive 数据库），不存在服务器、账号、同步、分析 SDK 或广告 SDK，
> 因此不构成「收集」，标签为 **Data Not Collected**。
>
> 本文件同时给出每项判断的证据与提审前的复核方法，请与 `PRIVACY.md`、App 内隐私政策页保持一致。

## 1. 逐项依据（App Store Connect ▸ App 隐私）

| # | 数据类型（Connect 中的分组） | 选择 | 判断依据 / 证据 |
|---|---|---|---|
| 1 | **联系信息**（姓名、邮箱、电话、地址、其他联系方式） | 不收集 | 无注册/登录、无账号体系，App 内没有任何要求输入联系方式的界面；无通讯录/邮件权限。 |
| 2 | **健康与健身** | 不收集 | 未接入 HealthKit，无健康相关功能。 |
| 3 | **财务信息**（支付信息、信用分、其他财务信息） | 不收集 | 交易金额、分类、备注等**仅写入本机** Hive 数据库；无支付、无银行卡、无内购、无订阅，不向任何服务器发送。本地存储不属于 Apple 定义的收集。 |
| 4 | **位置** | 不收集 | 未使用 CoreLocation；`Info.plist` 无任何定位权限描述。 |
| 5 | **敏感信息** | 不收集 | 无宗教、种族、性取向、健康等敏感字段的采集或上传。 |
| 6 | **通讯录** | 不收集 | 未接入 Contacts，无通讯录权限。 |
| 7 | **用户内容** ▸ 照片或视频 | 不收集 | 相机/相册仅在用户主动「拍照识别」时使用；图片在本机用 iOS Vision 识别，**不上传**，不长期保存原图（仅可能作为系统临时文件存在）。 |
| 8 | **用户内容** ▸ 音频数据 | 不收集 | 语音仅在用户按住「语音记账」时采集，交给 `SFSpeechRecognizer` 且强制 `requiresOnDeviceRecognition = true`；音频不写盘、不上传。设备端识别不可用时功能直接禁用并提示，**不会回退到服务器识别**。 |
| 9 | **用户内容** ▸ 客户支持 / 其他用户内容 | 不收集 | App 内无反馈上传通道、无用户生成内容、无社区功能。 |
| 10 | **浏览历史 / 搜索历史** | 不收集 | App 内无网页浏览、无联网搜索；账单页的本地筛选不上传。 |
| 11 | **标识符** ▸ 用户 ID | 不收集 | 无账号、无用户 ID。交易 ID 由 `uuid` 在本机随机生成，仅用于本地数据关联。 |
| 12 | **标识符** ▸ 设备 ID | 不收集 | 不读取 IDFA/IDFV，不接入广告或归因 SDK。 |
| 13 | **购买** | 不收集 | 无内购、无订阅、无付费墙。 |
| 14 | **使用数据**（产品交互、广告数据、其他） | 不收集 | 未集成任何统计/埋点/广告 SDK；App 内无网络请求代码。 |
| 15 | **诊断**（崩溃、性能、其他） | 不收集 | 未集成崩溃/性能采集 SDK。App Store Connect 中 Apple 平台自身提供的崩溃报告不属于 App 采集（不由 App 传输）。 |
| 16 | **其他数据** | 不收集 | 无以上未覆盖的数据类型。 |
| 17 | **Tracking（用于追踪的数据）** | 否 | 无 ATT 弹窗、无 IDFA、无跨 App/网站追踪、无数据经纪商共享。 |

### 1.1 三个汇总项的答案

| Connect 汇总项 | 答案 |
|---|---|
| Data Used to Track You | 无 |
| Data Linked to You | 无 |
| Data Not Linked to You | 无（即：不收集任何数据） |

## 2. 依赖与系统能力对照

`pubspec.yaml` 当前依赖及数据行为（**未新增任何依赖**）：

| 依赖 / 系统能力 | 用途 | 是否联网 | 是否收集数据 |
|---|---|---|---|
| `hive`、`hive_flutter` | 交易与设置的本地键值存储 | 否 | 否（只写本机沙盒） |
| `uuid` | 生成本地交易 ID | 否 | 否 |
| `intl` | 日期/数字格式化 | 否 | 否 |
| `image_picker` | 调用系统相机 / 相册选择器 | 否 | 否（仅把用户选择的文件路径交给 App） |
| `path_provider` | 获取本机沙盒目录 | 否 | 否 |
| `share_plus` | 用户主动导出时打开**系统分享面板** | 否（由用户选择目标 App） | 否（开发者不接收数据） |
| `flutter_localizations` | 中文本地化 | 否 | 否 |
| iOS Vision（`VNRecognizeTextRequest`） | 小票文字识别 | 否（纯设备端） | 否 |
| iOS Speech（`SFSpeechRecognizer`，强制设备端识别） | 语音转文字 | 仅设备端 | 否 |

> 网络证据：业务代码中未使用 `http`、`HttpClient`、`Socket`、`WebSocket`、`dio`、`url_launcher` 等网络能力；
> 无自建后端、无 API 域名。`share_plus` 仅在用户点「导出」后调起系统分享面板，数据是否离开设备由用户决定，且不经过开发者。

## 3. 权限与文案对应（`ios/Runner/Info.plist`）

| 键 | 用途（当前中文文案） | 触发时机 | 拒绝后的降级 |
|---|---|---|---|
| `NSCameraUsageDescription` | 扫描小票或账单截图，自动识别金额与商户，照片仅在本机处理，不会上传。 | 用户点「拍照识别」 | 提示可改用相册选图或手动记账 |
| `NSPhotoLibraryUsageDescription` | 从相册选择小票或账单截图进行识别，照片仅在本机处理，不会上传。 | 用户点「从相册选择」 | 提示可拍照或手动记账 |
| `NSMicrophoneUsageDescription` | 按住说话即可记账，录音仅在本机用于语音识别，不会上传。 | 用户按住「语音记账」 | 提示改用拍照或手动记账 |

> 权限说明已按「仅本机处理、不上传」口径撰写，与隐私政策一致；如后续修改文案，请同步更新本文件与 `PRIVACY.md`。

## 4. 提审前复核清单（每次发版都做）

- [ ] `grep -rn "http\|HttpClient\|Socket\|dio\|WebSocket\|url_launcher" lib/` 无业务网络调用
- [ ] `pubspec.yaml` 未新增分析/广告/推送/崩溃 SDK
- [ ] 断网 + 飞行模式实测：拍照识别、语音记账、保存、报表、导出全部可用（语音不可用时按设计禁用，而非偷偷走服务器）
- [ ] 首次触发对应功能时的 4 个权限弹窗文案与上表一致；拒绝授权后仍能手动记账
- [ ] 「清空数据」二次确认、JSON 备份恢复可用（这是「数据由用户掌控」的实证）
- [ ] App 内隐私政策页内容与 `PRIVACY.md` 一致，支持 URL 可访问
- [ ] Connect 隐私标签：全部不收集、Tracking 否；与版本发布说明一致
- [ ] 若未来引入云同步/统计/推送，**必须先改代码、改本文件、改 Connect 标签**，再提审

## 5. 需要留意的边界情况

1. **iCloud 设备备份**：App 沙盒数据可能被 iOS 纳入设备备份（若用户开启 iCloud 备份）。备份由 Apple 加密托管，开发者无法访问，Apple 不将其视为开发者「收集」数据；但若用户对此敏感，可在 iOS 设置中关闭该 App 的 iCloud 备份，或定期用 JSON 导出留存。
2. **系统分享导出**：用户把 CSV/JSON 分享到第三方 App 后，数据由该第三方处理，超出本 App 与开发者的控制范围，属于用户主动行为。
3. **系统语音识别的设备端限制**：`requiresOnDeviceRecognition = true` 是硬性代码要求；若实现被改为允许服务器识别，则隐私标签必须更新为「音频数据：收集」。
4. **第三方键盘 / 剪贴板**：App 不使用自定义键盘、不读取剪贴板，无相关风险。
