# 衡账 LedgerAI · App Store 截图方案（6.9" iPhone）

> 版本：`1.0.0+1`　语言：简体中文（可后续补英文）　设备：iPhone 竖屏
> 目标：6–8 张截图讲清「离线隐私 + 拍照/语音记账 + 报表预算 + 适老化」，前 3 张承担主要转化。

---

## 1. 规格与硬性要求

| 项目 | 要求 |
|---|---|
| 必传尺寸 | **6.9 英寸 iPhone：1320 × 2868 px（竖屏）**；若手头只有 6.7" 机型，用 1290 × 2796 px |
| 张数 | 3–10 张；**建议 6–8 张**（本方案 8 张，可删到 6 张） |
| 格式 | PNG 或 JPEG，RGB（**不要 alpha**），sRGB |
| 内容 | 必须是**真实 App 界面**；允许加营销文案与背景，但不得伪造界面或功能 |
| 状态栏 | 统一 9:41、满电、满格信号；不要出现调试 banner（`debugShowCheckedModeBanner: false` 已关闭） |
| 禁止项 | 其他平台/商店 logo、价格对比、「最/第一/唯一/国家级」等绝对化用语、「Beta/测试/开发版」字样、真实个人信息 |
| 上传 | App Store Connect ▸ 该版本 ▸「预览与截屏」▸ iPhone 6.9" 显示；按顺序上传，第一张即列表主图 |

> 只上传 6.9" 一组即可，App Store Connect 会自动为更小尺寸派生；若再上传 6.7" 一组，内容需与 6.9" 一致。

## 2. 统一视觉规范（后期排版）

- 画布：1320 × 2868；上下留白 ≥ 120px，左右 ≥ 90px。
- 背景：品牌绿渐变（`#10B981 → #059669`）或浅色 `#F6F7F9`，8 张统一；避免花哨插画抢主体。
- 标题：思源黑体 / PingFang SC Bold，字号 96–110px，白色（绿底）或 `#065F46`（浅底），行高 1.15。
- 副文案：字号 52–60px，透明度 80%，与标题间距 32px。
- App 截图：等比缩放到画布宽度的 82%–86%，圆角 12–16px，加轻微投影；**不要加 iPhone 外壳**（避免设备型号版权与过时感）。
- 8 张图共用同一套标题位置与截图位置，形成系列感；标题不超过两行。
- 文案风格：具体、可验证，不使用感叹号堆叠。

## 3. 八张截图清单

截图顺序 = Connect 中的展示顺序。每张的「主文案」≤ 12 字，「副文案」≤ 20 字。

### 01 首页概览
- **主文案**：本月花了多少，一眼看清
- **副文案**：收支、结余、预算进度实时汇总
- **画面**：首页 Tab —— 本月结余卡片、收入/支出、预算进度条、最近交易列表（DEMO 示例账本）。
- **操作路径**：启动 → 引导页「开始记账」→ 首页。

### 02 拍照记账
- **主文案**：拍张小票，自动记账
- **副文案**：本机识别金额、商户与分类
- **画面**：记账页「拍照识别」结果确认状态：示例小票识别出「麦当劳 / 餐饮 / 42.00」，金额、分类、日期已预填，可编辑。
- **操作路径**：首页「+」→「拍照识别」→ 选一张小票图 → 进入确认页。

### 03 语音记账
- **主文案**：说一句话，记好一笔
- **副文案**：「午饭 32 块」→ 自动填好金额与分类
- **画面**：语音记账状态：识别中的波纹/大按钮 + 识别结果「午饭 32 元 · 餐饮」。
- **操作路径**：首页「+」→「语音记账」→ 说一句示例。

### 04 报表分析
- **主文案**：钱花在哪，一目了然
- **副文案**：分类占比 + 近 6 个月趋势
- **画面**：报表 Tab —— 环形分类占比、趋势柱状/折线、一条本地建议卡片（如「餐饮占比偏高」）。
- **操作路径**：底部「报表」。

### 05 预算管理
- **主文案**：预算快超支，提前知道
- **副文案**：月度总预算 + 分类预算
- **画面**：预算 Tab —— 总预算 6000 元、已用 78%、分类预算（餐饮/交通/购物/娱乐）进度条与剩余金额。
- **操作路径**：底部「我的」→「预算」或预算入口。

### 06 数据与隐私（差异化重点）
- **主文案**：账本只存在你的手机
- **副文案**：不登录 · 不联网 · 不上传 · 无广告
- **画面**：设置页「数据与隐私」区域 —— 本地存储说明、导出 CSV/JSON、清空数据（带二次确认）三个入口；可叠加「Data Not Collected」小徽标（用文字，不用 Apple 官方图标）。
- **操作路径**：底部「我的」→ 数据/隐私区块。

### 07 账单与智能分类
- **主文案**：每笔都自动分好类
- **副文案**：餐饮、交通、购物…可随时修改
- **画面**：账单 Tab —— 按月份分组、分类图标与颜色、搜索/筛选条。
- **操作路径**：底部「账单」。

### 08 深色模式与适老化（可选）
- **主文案**：大字大按钮，父母也会用
- **副文案**：深色模式 · 高对比度 · 支持读屏
- **画面**：深色模式下的首页或大字号首页（字体放大 1.3×，按钮 ≥48pt）。
- **操作路径**：我的 → 外观 → 深色；系统字体调大后回到首页。

> 如果只做 6 张：保留 01、02、03、04、05、06（首页/拍照/语音/报表/预算/隐私），07、08 作为备用。

## 4. 用模拟器 + DEMO 数据抓原始截图（推荐流程）

前置：macOS + Xcode + Flutter；已 `flutter pub get`。App 的 DEMO 模式只会在账本为空时写入示例数据，**不会影响正常构建**（`lib/main.dart` 中 `AppState.isDemo` 控制）。

```bash
# 1) 启动 6.9" 模拟器（iPhone 18/17/16 Pro Max），统一状态栏 9:41
xcrun simctl list devices available | grep "Pro Max"
xcrun simctl boot "iPhone 18 Pro Max" && open -a Simulator
xcrun simctl status_bar "iPhone 18 Pro Max" override \
  --time "9:41" --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4
xcrun simctl ui "iPhone 18 Pro Max" appearance light

# 2) 以 DEMO 模式运行（示例账本 + 预算设置 + 已完成引导）
flutter run -d "iPhone 18 Pro Max" --dart-define=DEMO=true

# 3) 逐屏抓图（按提示在模拟器里切页；产物在 store/screenshots/raw/）
./scripts/capture_screenshots.sh
```

- 模拟器输出的截图是纯设备屏幕（不含模拟器窗口），6.9" 机型应为 **1320 × 2868**，脚本会自动用 `sips` 校验并提示尺寸异常。
- DEMO 数据见 `lib/core/demo_data.dart`：本月有工资 8500、午餐 42（拍照来源）、地铁 6、淘宝 189（语音来源）等，预算 6000，分类预算餐饮 2000/交通 600/购物 1000/娱乐 500 —— 截图中的金额与文案按此对齐，不要临时编造。
- 抓图后统一在 Figma / Sketch 里加标题与背景，导出 1320 × 2868 PNG。

### 4.1 模拟器的两个限制（必须知道的坑）

| 限制 | 影响 | 处理方式 |
|---|---|---|
| 模拟器没有相机 | 02 拍照记账无法真实拍摄 | 用「从相册选择」导入一张小票图；相册图片需存在模拟器照片库（拖进模拟器窗口即可） |
| 模拟器的本机语音识别常不可用 | 03 语音记账可能显示「本机语音识别不可用」提示 | 优先用**真机**（iPhone，iOS 16+，中文语音包已下载）截图后 Airdrop 到 Mac；或请 UI 层提供 DEMO 预填的「识别结果」状态（需 ui-core 配合，列为 Lead 待办） |

> `capture_screenshots.sh` 已内置 `--dart-define=DEMO=true`、状态栏覆盖与尺寸校验；若某台机器的设备名不同，用 `DEVICE_NAME="iPhone 17 Pro Max" ./scripts/capture_screenshots.sh` 覆盖。

## 5. 文案与事实的一致性检查

- 截图里出现的每个功能都必须在 App 内可复现；不夸大「AI」：只用「本机识别 / 自动分类 / 本地建议」措辞，**不写**「云端大模型」「AI 理财顾问」「智能投顾」。
- 「不登录 · 不联网 · 不上传」是核心卖点，需与 `PRIVACY.md`、隐私标签一致。
- 金额、商户、日期使用 DEMO 示例数据，不出现真实姓名、手机号、真实订单号。
- 不写「永久免费」「100% 准确」等绝对化表述；识别精度相关只说「可修改确认」。
